# Direction B — « Nuit et braise »

Sportive, premium, pensée pour la salle (écran lu à 1 mètre, entre deux séries).

- Fond **bleu nuit profond** (vers #0B1220), cartes légèrement plus claires (#141C2E), aucune ombre, liserés fins.
- Accent : **orange braise** (vers #FF6B2C) pour l’effort et les actions, dégradé braise → ambre pour les jauges ; bleu glacier (#7DD3FC) pour la récupération, le sommeil et le jeûne.
- Typographie condensée et grasse pour les titres et les chiffres (style affiche sportive), sans-serif sobre pour le texte.
- Données lumineuses : anneaux et courbes avec un léger halo, chiffres énormes.
- Silhouette « Mon corps » : corps anatomique stylisé gris anthracite, les muscles travaillés **s’illuminent** du jaune au rouge braise comme une carte de chaleur ; les muscles en retard restent éteints.
- Photographie : athlète en clair-obscur, éclairage de salle dramatique.
- Ton : énergie, défi, performance.
