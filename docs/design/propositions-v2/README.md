# Directions explorées (deuxième tour, 21 novembre 2026)

Toutes les images ont été générées avec ChatGPT via Codex (`run.ps1`), à partir du brief commun [BRIEF.md](BRIEF.md) et de la consigne propre à chaque direction (`DIRECTION-DEMANDEE.md` dans chaque dossier). Chaque dossier contient aussi la note de ChatGPT (`DIRECTION.md`). Les captures d’autres applications n’ont servi que d’**inspiration de principes**. Aucune marque, aucun texte et aucune couleur n’en a été repris.

## Décisions prises en chemin

1. **D pour la structure, avec l’énergie de B** (direction E).
2. **Le personnage de Picnic** est validé.
3. **Les boutons « exactement comme Picnic »**, mesurés sur une capture : environ 48 pt de haut, coins de 3 à 4 pt, contour de 1,5 pt, aucune ombre.
4. **La même bordure presque partout** : cartes, champs, pastilles, sélecteurs, listes, panneaux.
5. **Deux coachs** (une femme, un homme) plutôt qu’une coach seule : une coach seule à l’entrée parlait mal à une partie des hommes, un coach seul aurait fait fuir une partie des femmes. Le duo est à l’accueil, et le choix se fait au démarrage.
6. Après validation, **tous les médias sont régénérés proprement** avec ChatGPT ([medias/](../medias/README.md)).

Le design qui en découle est décrit dans [DESIGN.md](../DESIGN.md).
