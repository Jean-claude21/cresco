# Coach Cresco — femme : planche de référence et poses définitives

Personnage de l’app Cresco (sport, nutrition, jeûne). Image jointe : la coach telle qu’elle apparaît dans les maquettes ; garde son identité.

## Identité (à respecter à l’identique sur chaque image)
- Femme noire d’une trentaine d’années, souriante, chaleureuse, sportive et crédible (pas mannequin, pas caricature), silhouette athlétique naturelle.
- Cheveux bouclés volumineux, **bandeau orange braise #FF5A1F**.
- Tee-shirt noir ample, pantalon de jogging noir à **deux bandes braise** sur le côté, baskets blanches à détails braise, petite gourde parfois.
- Style : **illustration plate chaleureuse**, aplats de couleur, ombrages doux en deux tons, contour fin discret, mêmes proportions (environ 7 têtes), même visage sur toutes les images.

## Fichiers à produire (PNG, **fond transparent**, personnage entier centré, marge de 6 %, format carré 1024 × 1024 sauf la planche)
1. `reference.png` (1536 × 1024, fond blanc) : planche de référence : face, trois-quarts, dos, gros plan du visage (3 expressions : sourire, encouragement, réflexion), palette des couleurs avec codes hex.
2. `pose-salue.png` : main levée qui salue, l’autre main sur la hanche.
3. `pose-explique.png` : bras tendu paume ouverte vers la droite, comme pour présenter quelque chose.
4. `pose-carnet.png` : tient un carnet ouvert et le montre, sourire.
5. `pose-pouce.png` : pouce levé, encouragement.
6. `pose-reflechit.png` : main au menton, regard vers le haut, bienveillante.
7. `pose-celebre.png` : les deux bras levés, joie, petit saut.

Aucun texte, aucun logo, aucune marque.
