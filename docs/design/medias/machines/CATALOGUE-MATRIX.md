# Catalogue Matrix Fitness (force)

Lu le 22/11/2026 sur le catalogue officiel ([fr.matrixfitness.com, Force](https://fr.matrixfitness.com/fra/strength/catalog)) : **205 produits**, dont **175 postes d’exercice** et 30 rangements ou plateformes. Source brute : [matrix-catalogue-brut.txt](matrix-catalogue-brut.txt) ; ce tableau est généré par [catalogue_matrix.py](catalogue_matrix.py).

Chaque modèle est rattaché à une machine de Cresco (identifiant d’exercice, ou `material:` pour un équipement partagé). Une même machine existe dans plusieurs gammes : dans l’app, on coche le poste (par exemple « Presse pectorale convergente »), quelle que soit la gamme. Noms anglais officiels, noms français de Cresco. Les photos de l’app sont génériques, sans marque.

**Chaque poste d’exercice de Matrix a son équivalent dans Cresco**, avec sa photo dans « Ma salle ».
