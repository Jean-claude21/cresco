# Coach Karim : mouvements sur machine (lot-a)

Le personnage est **Karim**, exactement celui de la planche de référence jointe (visage, cheveux bouclés, barbe courte, t-shirt anthracite #282421, short noir à bandes braise #FF5A1F, bracelet éponge braise, baskets blanches et braise). Même style d’illustration que la référence : dessin propre, couleurs plates avec ombres douces, **fond blanc pur #FFFFFF**, aucun décor, aucun texte, aucun logo.

La machine est dessinée dans le même style : cadre anthracite #282421, coussins noirs, détails gris, sans marque. **Vue de profil stricte** (de côté), machine et personnage entiers dans chaque case, avec de l’air autour.

Pour chaque exercice, trois positions qui s’enchaîneront en boucle dans l’app : **départ**, **milieu**, **fin du mouvement**. Les trois cases d’un même exercice doivent être **cadrées exactement pareil** : même machine au même endroit, même taille, même point de vue ; seuls les membres de Karim et les parties mobiles de la machine bougent.

Les images jointes montrent Karim et **le rendu attendu** (planche validée : presse pectorale, tirage vertical, presse à cuisses, leg curl) : reproduis exactement ce style, ce cadrage et cette qualité.

## Planches
PNG **1024 × 1536** (portrait), **3 colonnes × 4 lignes** de cases égales (341 × 384). Une ligne par exercice : colonne 1 = départ, colonne 2 = milieu, colonne 3 = fin. Lignes inutilisées en blanc pur. Vue de profil sauf mention contraire.

`planche-1.png` :
1. **Adducteurs (Hip Adductor)** : vue de FACE exceptionnellement, assis, coussins contre l’intérieur des genoux : départ jambes écartées ; fin genoux serrés.
2. **Belt squat** : debout sur la plateforme, ceinture à la taille reliée au levier : départ debout ; fin cuisses parallèles au sol.
3. **Crunch à la poulie (Cable Crunch)** : à genoux face à la poulie haute, corde tenue près des tempes : départ buste droit ; fin buste enroulé, coudes vers les cuisses.
4. **Crunch à la machine (Abdominal Crunch)** : assis, poignées au-dessus des épaules : départ dos contre le dossier ; fin buste enroulé vers l’avant.

`planche-2.png` :
1. **Curl biceps surélevé à disques (Elevated Biceps Curl)** : debout, bras posés en hauteur sur le pupitre : départ bras tendus ; fin poignées près des épaules.
2. **Curl biceps à la machine (Biceps Curl)** : assis, coudes sur le pupitre : départ bras tendus ; fin poignées près des épaules.
3. **Dips assis à la machine (Seated Dip)** : assis, poignées le long du corps : départ coudes pliés, mains à hauteur des côtes ; fin bras tendus vers le bas.
4. **Développé couché à disques (Plate-Loaded Bench Press)** : allongé sur le banc de la machine : départ poignées près de la poitrine ; fin bras tendus vers le haut.

`planche-3.png` :
1. **Développé décliné à disques (Decline Bench Press)** : assis dos sur le dossier décliné : départ poignées près du bas de la poitrine ; fin bras tendus.
2. **Extension lombaire inversée (Reverse Hyperextension)** : buste à plat ventre sur le plateau, mains aux poignées, jambes pendantes dans le rouleau : départ jambes pendantes vers le bas ; fin jambes tendues à l’horizontale.
3. **Extension lombaire à la machine (Back Extension)** : assis, coussin dans le haut du dos : départ buste penché en avant ; fin buste redressé en arrière.
4. **Extension triceps à la poulie (Cable Pushdown)** : debout face à la poulie haute, coudes collés au corps : départ mains à hauteur de poitrine ; fin bras tendus vers le bas.

`planche-4.png` :
1. **Extension triceps à la machine (Triceps Extension)** : assis, coudes sur le pupitre : départ avant-bras pliés vers le haut ; fin bras tendus.
2. **Hip thrust debout (Standing Hip Thrust)** : debout, coussin contre les hanches, buste penché en avant : départ hanches en arrière ; fin hanches poussées en avant, corps droit.
3. **Leg curl allongé (Lying Leg Curl)** : allongé sur le ventre, boudin derrière les chevilles : départ jambes tendues ; fin talons vers les fesses.
4. **Leg curl à genoux (Kneeling Leg Curl)** : un genou sur le coussin, avant-bras sur l’appui, l’autre cheville sous le boudin : départ jambe tendue ; fin talon vers la fesse.
