# Coach Karim : mouvements sur machine (essai, images clés)

Le personnage est **Karim**, exactement celui de la planche de référence jointe (visage, cheveux bouclés, barbe courte, t-shirt anthracite #282421, short noir à bandes braise #FF5A1F, bracelet éponge braise, baskets blanches et braise). Même style d’illustration que la référence : dessin propre, couleurs plates avec ombres douces, **fond blanc pur #FFFFFF**, aucun décor, aucun texte, aucun logo.

La machine est dessinée dans le même style : cadre anthracite #282421, coussins noirs, détails gris, sans marque. **Vue de profil stricte** (de côté), machine et personnage entiers dans chaque case, avec de l’air autour.

Pour chaque exercice, trois positions qui s’enchaîneront en boucle dans l’app : **départ**, **milieu**, **fin du mouvement**. Les trois cases d’un même exercice doivent être **cadrées exactement pareil** : même machine au même endroit, même taille, même point de vue ; seuls les membres de Karim et les parties mobiles de la machine bougent.
